# Save On Moon-Crash

In Majora's Mask, the penalty for letting the clock run out and the moon crash is losing all progress from that cycle.
However, because the original game deleted owl saves after they're loaded (and the only other way to save was with the Song of Time),
there was never a need for the game to save after a moon crash, only to delete your cycle progress from memory.

However, when using Zelda64Recompiled's autosave system (or LittleCube's Owls Never Quit mod), the deletion of owl saves is disabled,
and therefore a moon crash can be undone by reloading your save. This is a perfectly fine QoL feature (especially for those new to the game),
but some players (myself included) may enjoy the original threat of losing progress if the moon falls.

For those players, this mod exists. All it does is trigger an autosave when the moon crashes, thus overriding your save file and deleting that cycle's progress.
